## 학습 흐름 (모든 판 공통)

1. **프레임**: `cut_frames.py` 가 라벨이 가리키는 프레임을 서버에서 영상으로 다시 뽑았다. PC 에서 8GB 를 옮기지 않으려고 했고, 같은 코드 · 같은 영상이라 서브샘플 결과(파일명 = 순번)가 같다
2. **라벨**: `srv_relabel.py` 가 참조샷 기준으로 SAM2 자동 라벨을 다시 만들었다(09-02 17:08 ~ 17:23, 영상 37개 · 탭 프레임 265개 → 라벨 9,188장)
   - 실행하면 이전 `labels` · `boxs` 를 먼저 지운다
   - 서버에 SAM2 `_C` 확장이 없어 구멍 메우기(fill_holes) 후처리는 빠졌다
3. **학습**: `run_train_parts.py` 가 백엔드의 `start_multiclass` 를 직접 불렀다(GPU 2)
   - `medicine`(프레임 없이 라벨만 남은 부품)은 기본 제외, `_test` 로 끝나는 부품은 항상 제외
   - `XR_EXPECT` 에 부품 수를 주면 그 수와 다를 때 학습 전에 멈춘다(테스트 부품이 섞인 37종으로 6시간을 돈 실수 뒤에 넣은 안전장치)
4. **학습 이미지 구성**: 실촬 + 배경 합성 + 배경 사진 567장
   - 배경 합성: 실촬의 3배가 목표. 부품을 SAM2 로 오려 낸 이미지(누끼)를 부품당 최대 60장 골라 배경에 붙이고, 판넬 가림 2종을 넣었다
   - 합성 결과는 합성 보관소(`_synth_pool`)에 적립해 다음 판에서 다시 썼다
5. **설정(모든 판 같음)**: yolo11m.pt · 100 에폭 · imgsz 640 · batch 32 · workers 16 · cache ram · mixup 0.2 · erasing 0.4 · degrees 15
6. **평가**: `Igb_gearbox` 평가영상 test1 ~ 4 의 프레임별 검출률(부품이 하나라도 잡힌 프레임 비율). 사람 GT 가 없는 간접 지표다. test3 · 4 는 기체에 장착된 구간이다

주의
- `data.yaml` 의 val 이 train 과 같은 폴더라, 학습 곡선의 mAP50 0.995 는 의미가 없다
- best.pt 의 git 필드(02242c4)는 서버 레포 HEAD 가 찍힌 것이다. 실제로 학습한 코드는 이 폴더의 백엔드 복사본이다
