프로젝트 배경

헬기 정비 부품을 카메라로 자동 인식(탐지)하는 AI 를 만들고 있습니다. AI 학습에는 이미지마다 부품 위치를 표시한 정답 박스(라벨)가 필요한데, 이를 사람이 일일이 그리는 대신 자동으로 만드는 방법(오토라벨링) 7가지를 실험하고 비교했습니다.

각 방법마다 같은 틀로 기록했습니다: ① 어떤 데이터를 어떻게 사용했나 → ② 만들어진 라벨이 실제로 어떻게 생겼나(정답과 비교) → ③ 수치 성적과 판정.

용어뜻

Pseudo-labeling 채택

의사 라벨링(Pseudo-labeling)은 라벨이 없는 데이터에 모델이 예측한 값을 임시 라벨로 지정해 학습에 재활용하는 준지도학습 기법입니다.

실험 순서

  1. 1차 모델: 순수 YOLO 모델에 기계부품 데이터(bolt·nut·gear·bearing) 10~15%(149장)를 학습시킨다.
  2. 임시 학습 데이터 생성: 1차 모델에게 라벨이 없는 데이터 65~70%(647장)를 예측시키고, 신뢰도(confidence)가 0.6 이상인 라벨만 채택.
  3. 2차 모델: 순수 YOLO 모델에 1의 학습데이터와 2의 결과(0.6 이상 데이터)를 학습시킨다.
  4. 임시 학습 데이터 효과 검증: 1차 모델과 2차 모델의 평가지표를 비교한다.

실제 코드

scripts/labeling/pseudo_utils.py - predict_boxes()예측 + conf 필터. 1차 모델이 미라벨 이미지를 추론하고 신뢰도 0.6 이상만 통과시킴 (읽기 쉽게 풀어 쓴 것)
results = model.predict(source=unlabeled_images, stream=True)
for image, result in zip(unlabeled_images, results):
    accepted = [(cls, box) for cls, box, conf in result.boxes
                if conf >= 0.6]           # 신뢰도 0.6 미만 예측은 버림
    yield image, accepted
scripts/labeling/auto_labeling.py저장. predict_boxes 가 통과시킨 박스를 YOLO 라벨(.txt)로 기록
for image, accepted in predict_boxes(model, unlabeled_images, conf=0.6):
    # 이미지와 같은 파일명 .txt 가 YOLO 의 짝 규칙
    save_label(labels_dir / f"{image.stem}.txt", accepted)
scripts/training/train_pipeline.py재학습. 1차 모델 가중치가 아니라 순수 YOLO 에서 다시 시작

            epochs=100)
# 게이트: 새 모델 mAP50 가 기존보다 낮으면 배포하지 않고 폐기

상호 일관성 매칭 부분 성공

실험 순서

  • 방식: 등록 폴더(부품 1종)의 SAM 후보 중 '다른 모든 사진에도 비슷한 물체가 있는 후보'를 DINOv2 로 식별해 라벨링
  • 적용 ①: 사진 묶음 시뮬 (부품 크롭 2종 × 15장) → 성공
  • 적용 ②: 실사 기어박스 영상 49프레임 → 실패 (한 장면 영상은 배경도 매 프레임 등장해 매트·드릴·사람까지 오채택)
  • 교훈: 채택률 98%라는 수치만 보면 합격이었으나, 육안 검증이 실패를 적발

실제 코드

scripts/labeling/register_part.py - label_one_part()상호 일관성 점수 - 읽기 쉽게 풀어 쓴 것. 실패 원인이 이 수식 자체에 있음
# 사진 i 의 후보 하나하나에 대해:
# "다른 모든 사진에도 이것과 닮은 물체가 있는가" 를 점수로 만든다
score = 0
for j in range(len(all_photos)):
    if j == i:
        continue
    best = max(similarity(candidate, other) for other in photo_j.candidates)
    score += best                        # 사진 j 에서 가장 닮은 후보와의 유사도
score = score / (len(all_photos) - 1)    # 전체 평균

if score >= 0.55:                        # 임계값 통과 -> 부품으로 채택
    keep(candidate)

# 함정: 배경(매트·드릴·사람)도 모든 프레임에 등장한다
# -> 배경 후보도 score 가 높게 나와 오채택 (한 장면 영상에서 실패한 이유)

1탭 참조 매칭 채택

실험 순서

  • 방식: 등록 화면에서 부품을 한 번 클릭 → SAM 포인트 분할로 참조 크롭 확보 → 모든 프레임의 SAM 후보를 참조와 DINOv2 유사도(임계값 0.7)로 매칭
  • 데이터: 실사 기어박스 영상 (1차 33프레임 → 완결 193프레임)
  • 검증: 생성 라벨로 학습 후, 학습에 안 쓴 별도 영상(16프레임)에서 탐지 확인
