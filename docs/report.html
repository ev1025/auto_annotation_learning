프로젝트 배경

헬기 정비 부품을 카메라로 자동 인식(탐지)하는 AI 를 만들고 있습니다. AI 학습에는 이미지마다 부품 위치를 표시한 정답 박스(라벨)가 필요한데, 이를 사람이 일일이 그리는 대신 자동으로 만드는 방법(오토라벨링) 7가지를 실험하고 비교했습니다.

각 방법마다 같은 틀로 기록했습니다: ① 어떤 데이터를 어떻게 사용했나 → ② 만들어진 라벨이 실제로 어떻게 생겼나(정답과 비교) → ③ 수치 성적과 판정.

Pseudo-labeling 채택

의사 라벨링(Pseudo-labeling)은 라벨이 없는 데이터에 모델이 예측한 값을 임시 라벨로 지정해 학습에 재활용하는 준지도학습 기법입니다.

사용 기술

YOLO (yolo26s)실시간 객체 탐지 모델. 이미지에서 물체의 위치(박스)와 클래스를 예측한다
self-training모델이 스스로 만든 예측을 임시 라벨로 삼아 다시 학습에 쓰는 준지도학습 기법

실험 순서

입력공개 기계부품 데이터 (bolt·nut·gear·bearing). 초기 라벨셋 10~15%만 라벨을 남기고 나머지는 라벨을 숨김
↓
1차1차 모델 학습 — 순수 YOLO(COCO 사전학습)에 초기 라벨셋 149장만 학습
↓
2임시 학습 데이터 생성 — 1차 모델이 미라벨 데이터 647장을 예측, 신뢰도(confidence) 0.6 이상만 라벨로 채택 (622장)
↓
2차2차 모델 학습 — 순수 YOLO 에 [초기 라벨 + 임시 라벨]을 합쳐 처음부터 재학습
↓
검증효과 검증 — 어느 학습에도 안 쓴 평가셋 199장에서 1차 vs 2차 성능 비교 → mAP50 0.8354 → 0.8586 상승 → 채택

실제 코드

예측 + conf 필터. 1차 모델이 미라벨 이미지를 추론하고 신뢰도 0.6 이상만 통과시킴 (읽기 쉽게 풀어 쓴 것)

scripts/labeling/pseudo_utils.py - predict_boxes()
results = model.predict(source=unlabeled_images, stream=True)
for image, result in zip(unlabeled_images, results):
    accepted = [(cls, box) for cls, box, conf in result.boxes
                if conf >= 0.6]           # 신뢰도 0.6 미만 예측은 버림
    yield image, accepted

저장. predict_boxes 가 통과시킨 박스를 YOLO 라벨(.txt)로 기록

scripts/labeling/auto_labeling.py
for image, accepted in predict_boxes(model, unlabeled_images, conf=0.6):
    # 이미지와 같은 파일명 .txt 가 YOLO 의 짝 규칙
    save_label(labels_dir / f"{image.stem}.txt", accepted)

텍스트 제로샷 (Grounding DINO) 탈락

학습되지 않은 객체를 설명 문구만으로 찾는 방법으로, 이미지의 객체와 프롬프트의 유사도를 판단하여 클래스를 부여하는 방식.

사용 기술

Grounding DINO글(프롬프트)로 지정한 물체를 이미지에서 찾는 개방어휘 객체 탐지기. 텍스트·이미지 매칭이라 별도 학습이 필요 없다

실험 순서

입력이미지 1장 + 고정 영어 프롬프트 4개 (metal hex bolt screw → bolt 등, 매 이미지 동일)
↓
1영역·텍스트 인코딩 — 이미지에서 물체가 있을 법한 영역 후보를 뽑고, 프롬프트 4개를 각각 숫자 벡터로 변환
↓
2유사도 매칭 — 각 영역 후보와 프롬프트의 유사도를 계산해 0.35 이상만 남기고, 가장 닮은 프롬프트를 그 박스의 클래스로 결정
↓
3후처리 — 겹친 중복 박스(NMS)와 화면을 덮는 거대 박스 제거
↓
출력자동 라벨 — 탐지된 객체마다 박스 1개 + 클래스 1개 (프롬프트 4개는 '가능한 클래스 목록'일 뿐, 박스 수 = 이미지 속 통과한 객체 수. 볼트 5개면 bolt 박스 5개)
↓
채점정답을 숨긴 평가셋 204장에 적용, 숨긴 정답과 IoU 0.5 대조 → 정밀도 0.238 / 재현율 0.415
↓
탈락탈락 사유 — 물체 위치는 곧잘 찾지만(재현율 0.42) hex bolt·hex nut 같은 유사 부품의 클래스를 자주 틀려, 오탐이 맞춘 것의 3배. 무검수 라벨 기준(정밀도 0.87)에 크게 미달.

초록 = 모델 박스, 빨강 = 정답 라벨 (한 이미지에 겹쳐 표시)

실험 결과

정밀도 0.2382 → 무검수 라벨 기준(0.87) 미달로 탈락

Grounded-SAM 타이트박스 탈락

방법 2의 틀린 라벨이 '박스가 헐렁해서'인지 검증한 방식. SAM 으로 박스를 물체 경계까지 좁혀도(위치 개선) 성능이 그대로라면, 문제는 위치가 아니라 클래스라는 뜻.

사용 기술

Grounding DINO글(프롬프트)로 지정한 물체를 이미지에서 찾는 개방어휘 객체 탐지기. 텍스트·이미지 매칭이라 별도 학습이 필요 없다
SAM이미지 속 물체를 픽셀 단위로 분할하는 모델. 물체 후보 영역(마스크)을 만든다 · 여기선 생성된 박스를 물체 경계까지 좁히는 데 사용

실험 순서

입력이미지 + 영어 프롬프트 4개 (방법 2와 동일)
↓
1박스 생성 — Grounding DINO 로 프롬프트에 맞는 박스 생성 (방법 2와 동일). 박스가 물체보다 헐렁하게 나옴
↓
2타이트닝 — SAM 마스크로 각 박스의 네 변(좌표)을 물체의 픽셀 경계까지 좁힘. 위치·크기만 바뀌고 클래스는 그대로
↓
채점평가셋 204장, 숨긴 정답과 IoU 0.5 대조 → 정밀도 0.239 (방법 2의 0.238과 사실상 동일)
↓
탈락탈락 사유 — 위치는 맞혔지만 '무슨 객체인지'를 못 맞힘. 박스를 아무리 타이트하게 해도 성능이 안 오른다는 것은, 틀린 원인이 박스 여백(위치)이 아니라 클래스 오분류라는 뜻. (맞은 박스 IoU 는 DINO 원본 0.908 > SAM 0.876 로 오히려 과수축) → 다음은 클래스 판별력을 높이는 시각 매칭(방법 4·5)으로

SAM + CLIP 갤러리 탈락

텍스트 대신 '참조 이미지'와 비교하는 방식. SAM 이 자른 후보를 CLIP 임베딩으로 참조 갤러리와 유사도 매칭해 클래스를 부여.

사용 기술

SAM이미지 속 물체를 픽셀 단위로 분할하는 모델. 물체 후보 영역(마스크)을 만든다
CLIP이미지·텍스트를 같은 공간의 벡터로 바꾸는 임베딩 모델. 크롭 간 유사도 비교에 쓴다

실험 순서

준비참조 갤러리 구축 — train 정답에서 클래스마다 견본 크롭을 10장씩 오려 모음 (사람 손·사전 라벨이 필요한 사전 작업)
↓
입력라벨을 붙일 이미지 (라벨링 대상에는 정답 미사용)
↓
1후보 분할 — SAM 이 이미지의 물체 후보를 전부 분할
↓
2임베딩 — 각 후보 크롭을 CLIP 으로 숫자 벡터화
↓
3갤러리 매칭 — 후보 벡터를 참조 갤러리 견본들과 유사도 비교, 가장 닮은 클래스 부여
↓
채점평가셋 204장, IoU 0.5 → 최고 정밀도 0.60

상호 일관성 매칭 부분 성공

참조 갤러리 없이, '등록한 모든 사진에 공통으로 나오는 물체 = 그 부품'이라고 보고 라벨링하는 방식. 클래스 분류 자체를 없앰.

사용 기술

SAM이미지 속 물체를 픽셀 단위로 분할하는 모델. 물체 후보 영역(마스크)을 만든다
DINOv2이미지를 질감·형상 특징 벡터로 바꾸는 자기지도 임베딩 모델. 크롭 간 유사도 비교에 쓴다

실험 순서

입력등록 폴더 (부품 1종, 사진 여러 장). 폴더당 부품 1종
↓
1후보 분할 — SAM 이 각 사진의 물체 후보를 분할
↓
2임베딩 — 각 후보를 DINOv2 로 벡터화
↓
3공통 물체 탐색 — '다른 모든 사진에도 닮은 것이 있는 후보'를 점수화(임계값 0.55) → 공통 등장 물체 = 그 부품
↓
출력공통 물체만 라벨
↓
결과부분 성공 — 사진 묶음 시뮬은 채택률 100%. 그러나 실사 영상은 배경(매트·드릴·사람)도 매 프레임 등장해 오채택 (채택률 98%였지만 육안 검증이 실패 적발) → 영상 등록은 방법 7로 대체

실제 코드

상호 일관성 점수 - 읽기 쉽게 풀어 쓴 것. 실패 원인이 이 수식 자체에 있음

scripts/labeling/register_part.py - label_one_part()
# 사진 i 의 후보 하나하나에 대해:
# "다른 모든 사진에도 이것과 닮은 물체가 있는가" 를 점수로 만든다
score = 0
for j in range(len(all_photos)):
    if j == i:
        continue
    best = max(similarity(candidate, other) for other in photo_j.candidates)
    score += best                        # 사진 j 에서 가장 닮은 후보와의 유사도
score = score / (len(all_photos) - 1)    # 전체 평균

if score >= 0.55:                        # 임계값 통과 -> 부품으로 채택
    keep(candidate)

# 함정: 배경(매트·드릴·사람)도 모든 프레임에 등장한다
# -> 배경 후보도 score 가 높게 나와 오채택 (한 장면 영상에서 실패한 이유)

포인트 참조 매칭 채택

부품 위치를 점 1개로 지정하면, 그 점의 물체를 '기준'으로 삼아 전 프레임에서 닮은 것을 찾아 라벨링하는 방식. 배경은 기준과 안 닮아 오채택이 원천 차단된다. (운영에선 화면 탭 1번, 이번 실험에선 프레임에서 부품 좌표를 직접 골라 지정)

사용 기술

SAM이미지 속 물체를 픽셀 단위로 분할하는 모델. 물체 후보 영역(마스크)을 만든다 · 여기선 지정한 점(포인트) 하나로 분할해 참조 크롭도 확보
DINOv2이미지를 질감·형상 특징 벡터로 바꾸는 자기지도 임베딩 모델. 크롭 간 유사도 비교에 쓴다

실험 순서

입력등록 영상/사진 + 부품 위치를 점 1개로 지정 (운영: 화면 탭 1번 / 이번 실험: 프레임에서 부품 좌표를 골라 ref.txt 에 기입)
↓
1참조 확보 — SAM 포인트 분할로 지정한 점이 속한 물체를 오려 '기준 사진' 확보
↓
2임베딩 — 모든 프레임의 SAM 후보를 DINOv2 로 벡터화
↓
3참조 매칭 — 기준 사진과 유사도 0.70 이상만 채택 + NMS·포함 억제로 중복 제거
↓
출력부품만 라벨 (기준과 안 닮은 배경은 원천 배제 → 오채택 0)

for frame in all_frames:
    for candidate in sam_candidates(frame):      # SAM 이 찾은 물체 후보들
