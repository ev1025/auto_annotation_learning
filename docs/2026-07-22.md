### 2.2 후속 검증 3종

| 검증 | 결과 |
|------|------|
| 시드 3반복 (26s vs v8s) | mAP50 평균: v8s 0.897 ±0.007 / 26s 0.894 ±0.001 → **v8s의 1위(0.905)는 시드 운**. mAP50-95 평균은 26s 우위(0.751 vs 0.746), 분산은 26s가 1/6 |
| 300ep 연장 (v8s·11n) | 100ep 대비 개선 없음(조기종료 발동) → epochs 100 유지 |
| 26n 공식 레시피 (245ep·lr0 0.0054·MuSGD) | 0.868 < 기본 100ep 0.880 → 소규모 데이터에 레시피 역효과 |

### 2.3 선정: YOLO26s @ 640

- 정확도 동급(mAP50-95 평균 1위) + 시드 분산 최소 → 자동 재학습 반복 시 품질 일관성
- 지연 최단(7.0ms/143.9fps): 파라미터 3배인 v8n보다 빠름 = NMS-free 구조 효과, Thor TensorRT 적합
- 입력 1280은 전 모델에서 정확도 이득 없이 지연 1.5~2배 → 640 확정
- 반영: `config.PRETRAINED = yolo26s.pt`, README 5.5

## 3. 아키텍처 피벗 (학습 데이터 원천 변경)

- **기존**: 3D 렌더 합성 데이터(어노테이션 자동 투영)로 학습
- **변경**: 사용자 업로드 부품 사진(영상 프레임 포함)으로 학습. 2D→3D 변환은 병렬 수행하되 XR 표시용으로만 사용
- **사유**: 2D→3D 변환이 학습 어노테이션에 쓸 만큼 정교하지 않을 것으로 판단
- **파생**: 도메인 갭 문제 소멸 / 새 병목 = 수량 / 클래스 정의 = 업로드 폴더명으로 해소 / 렌더 공급 조건(도메인 랜덤화 요구) 폐기 / 등록·오토러닝은 PC 측, XR 기기는 탐지 결과만 소비

<br>

## 4. 등록 자동 라벨링 방식 선정 (실측 실험 여정)

정답 있는 test 204장을 "라벨 없는 척" 라벨링 후 정답과 IoU 0.5 채점:

| 순서 | 시도 | 정밀도 | 판정 |
|------|------|--------|------|
| 1 | Grounding DINO 텍스트 프롬프트 | 0.215 | 유사 부품 클래스 혼동(접시→gear)으로 탈락 |
| 2 | + NMS·거대박스 제거 | 0.238 | 중복은 부차적 원인 |
| 3 | + 임계값 0.5 상향 | 0.292 | 재현율 반토막, 근본 해결 아님 |
| 4 | Grounded-SAM(SAM 타이트박스) | 0.239 | 박스 여백은 문제 아니었음(TP IoU: DINO 0.908 > SAM 0.876) |
| 5 | SAM 전체분할 + CLIP 갤러리 | 0.600 | 텍스트→시각 매칭 전환으로 2.5배 도약 |
| 6 | SAM + DINOv2 갤러리 | **0.927** (임계값 0.85) | 고정밀 운영점 최초 달성 (클래스별 P: bearing·gear 1.00) |
| 7 | 상호 일관성 매칭 (업로드=부품 1종 활용) | 시뮬 100% 채택 | 실사 영상에서는 실패(아래) |
| 8 | **1탭 참조 매칭** | 배경 오채택 0 | **최종 채택** |

**실사 검증에서 잡은 결함과 해결**:
- 기어박스 정비 영상(고정 배경+손+공구) 49프레임에서 상호 일관성 매칭이 매트·드릴·사람까지 오채택 → "배경이 사진마다 바뀐다" 가정이 한 장면 영상에서 붕괴 (수치는 98% 채택으로 좋아 보였으나 미리보기 육안 검증이 실패를 적발)
- 해결 = **1탭 참조**: 등록 화면(PC)에서 부품을 한 번 클릭 → SAM 포인트 분할로 참조 크롭 → 전 프레임 DINOv2 유사도 매칭. 같은 영상에서 기어박스만 정확히 라벨(33장 중 20장 채택, 오채택 0)
